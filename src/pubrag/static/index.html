Questions-réponses sourcées sur mes publications en génétique humaine. Chaque affirmation cite son article ; hors du corpus, le système refuse.

Chargement du corpus…

Entrée pour lancer, Maj+Entrée pour un saut de ligne. La recherche fonctionne sans clé API ; la réponse rédigée en demande une.

Le garde-fou amont : relief de chaque question

Le relief mesure l'écart entre le passage le plus proche et le passage médian. Une question couverte par le corpus présente un pic ; une question hors sujet est uniformément moyenne avec tout. À gauche du seuil, le système refuse sans appeler le modèle.
